# ИИ-бот учёта семейных расходов

Telegram-бот, который понимает траты на естественном языке («кофе 350», «поход в рестик 7698 вчера»),
и веб-панель владельца семьи. Многосемейный режим: семью можно создать или вступить в неё по приглашению.
Бэкенд на Go (один бинарник), PostgreSQL, запуск одним `docker compose`.

Архитектура и план: [docs/architecture.md](docs/architecture.md).

> Статус: готовы этапы 0–9 — слой данных, семьи и приглашения, часовые пояса, REST API панели с авторизацией
> ([api/openapi.yaml](api/openapi.yaml)), фильтр сообщений, распознавание категорий и устойчивый LLM-клиент
> (ретраи, circuit breaker, fallback-провайдер, учёт токенов), ИИ-агент с инструментами, Telegram-бот с онбордингом и веб-панель.

## Запуск

```bash
cp .env.example .env   # заполнить TELEGRAM_BOT_TOKEN и LLM_*
docker compose up --build
```

Проверка: `curl localhost:8080/readyz`. Панель: http://localhost:3000 — напишите боту «панель» и откройте ссылку.

Локальная разработка: `make run` поднимает Postgres в docker и запускает сервер через `go run`.

## Режимы авторизации панели

| `PANEL_AUTH_MODE` | Поведение |
|---|---|
| `magic_link` (по умолчанию) | Владелец пишет боту «панель» и получает одноразовую ссылку входа |
| `none` | Без авторизации, панель привязана к одной семье (`PANEL_FAMILY_ID`). Только для локального демо |

Отход от формулировки задания («авторизация не нужна») сделан из-за многосемейности: без авторизации
панель показывала бы данные всех семей.

## Распознавание трат и категорий

Сообщение проходит конвейер, и LLM вызывается только в конце и только когда без неё не обойтись:

1. **Фильтр правил** (0 токенов): длина, стоп-слова и запрещённые темы («сделай домашку», «какая ты модель»,
   «игнорируй инструкции»), разбор суммы («1 200 р», «1.5к», «2 тыс») и даты («вчера», «в пятницу», «12.10»).
2. **Словарь** [config/synonyms.yaml](config/synonyms.yaml): ~250 терминов и ~900 форм, сравнение по основам
   слов (стеммер Портера) и уменьшительным формам: «рестик», «в Пятёрочке», «мандаринчики».
3. **Кэш выученных слов** в БД (`learned_terms`).
4. **Онлайн-тезаурус**: для незнакомого слова берутся гиперонимы и синонимы из
   [Викисловаря](https://ru.wiktionary.org) («пельмени» → «блюдо» → еда). Наружу уходит только одно слово, не
   текст сообщения. Результат кэшируется, при сбоях сервис отключается на 5 минут. Выключается
   `THESAURUS_ENABLED=false`.
5. **LLM** — только для запросов, изменений, нескольких трат в одном сообщении и слов, которые не распознал никто
   выше. Простая трата с известной категорией («кофе 350») записывается вообще без LLM.

## Веб-панель

React + Vite + TypeScript, собирается в Docker (Node на машине не нужен) и раздаётся nginx с того же origin, что и
API (`/api` проксируется на `app:8080`), поэтому CORS не нужен. Есть обзор трат за период с итогами, графиками по
категориям, дням и людям, фильтры (член семьи, период, категории, поиск с синонимами), добавление, правка и удаление
трат (конфликт версий показывается понятным сообщением), участники (подписи, удаление, передача владения),
приглашения и настройки семьи. Тема: светлая, тёмная или авто. Авто по часам устройства: по умолчанию тёмная с 18:00
до 08:00, часы настраиваются.

Разработка панели с горячей перезагрузкой (API на :8080):

```bash
docker run --rm -it -p 3000:3000 -e API_URL=http://host.docker.internal:8080 -v "$PWD/web":/app -w /app node:22-alpine sh -c "npm ci && npx vite --host 0.0.0.0"
```
